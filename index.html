영상 호환성 (faststart)

영상 파일의 메타데이터(moov atom) 위치를 메모리 안에서만 앞쪽으로 옮겨, 큰 영상이나 호환성이 떨어지는 MP4를 빠르게 열 수 있게 해줍니다. 원본 파일은 절대 수정되지 않습니다.

✅ 켜면 좋은 경우

  • iPad/iPhone에서 큰 영상(2GB 이상)이 안 열릴 때
  • "영상을 불러오지 못했습니다" 오류가 나올 때
  • 로딩이 1분 이상 걸리는 영상

⚠️ 알아두세요

  • 처음 영상 분석에 몇 초가 추가될 수 있습니다 (파일 구조에 따라 다름)
  • 원본 파일은 그대로이며 디스크에 새 파일을 만들지 않습니다 (메모리 안에서만 동작)
  • 이미 faststart로 만들어진 파일은 자동으로 건너뛰므로 끄지 않아도 됩니다
  • iPad에서 2GB를 넘는 파일은 브라우저 안 변환을 건너뜁니다. 재생이 안 되면 데스크톱에서 H.264/AAC MP4 + faststart로 변환하거나 분할해주세요
  • HEVC/H.265 같은 코덱 비호환 문제는 해결하지 못합니다 (이건 PC에서 H.264로 변환해야 함)
  • 드물게 비표준 MP4에서 실패하면 자동으로 원본으로 되돌립니다

🔧 동작 원리: 파일 끝에 있는 moov 박스를 메모리에 읽어 청크 위치 정보를 보정한 뒤, 가상의 [ftyp][moov][mdat] 순서를 가진 blob을 만들어 영상 요소에 전달합니다. 단, iPad의 대용량 파일은 이 가상 blob 등록 단계에서 실패할 수 있어 안전하게 원본 파일 등록 후 외부 변환을 안내합니다.

홈 화면 앱 (PWA)

홈 화면에 추가하면 주소창과 탭바 없이 진짜 전체화면으로 사용할 수 있어요. CSS 확대 모드와 함께 쓰면 iPad에서 더블탭/2배속 제스처 + 풀스크린이 모두 가능해집니다.

현재 실행 모드 브라우저

iPad / iPhone (Safari)

  1. 주소창 옆 또는 하단 공유 아이콘(⬆️) 탭
  2. 스크롤해서 “홈 화면에 추가” 선택
  3. 이름 확인 후 “추가” 탭
  4. 홈 화면의 아이콘으로 실행 → 주소창/탭바 사라짐

Android (Chrome): 메뉴(⋮) → “앱 설치” 또는 “홈 화면에 추가”

데스크톱 (Chrome / Edge): 주소창 끝의 설치 아이콘 클릭
